# AccessGraph

Сервис для построения доступных маршрутов по городу. Учитывает наличие пандусов, качество покрытия и жалобы жителей, чтобы находить путь не «как короче», а «как удобнее» для людей на колясках, мам с колясками и слабовидящих.

Проект сделан в рамках учебного задания по проектной ориентации.

## Что умеет

- Загружает карту пешеходных дорожек из OpenStreetMap через OSMnx
- Назначает штрафы участкам дороги за ступени, отсутствие пандусов и плохое покрытие
- Строит маршрут алгоритмом "Дейкстры" с учётом этих штрафов
- Анализирует текстовые жалобы (NLP) и помечает проблемные места на графе
- Отдаёт результат через REST API (FastAPI)

## Стек

- Python 3.10+
- OSMnx, NetworkX — работа с графами и картами
- FastAPI — REST API
- Pandas — обработка данных
- Transformers (Rubert) — анализ жалоб
- Folium — визуализация маршрутов
