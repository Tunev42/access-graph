# AccessGraph

Сервис для построения доступных маршрутов по городу. Учитывает наличие пандусов, качество покрытия и жалобы жителей, чтобы находить путь не «как короче», а «как удобнее» для людей на колясках, мам с колясками и слабовидящих.

Проект сделан в рамках учебного задания по проектной ориентации, но с прицелом на реальное применение.

## 5W: О чём проект и зачем он нужен

- **Что?** Это API и набор скриптов, которые берут карту города, назначают "штрафы" опасным участкам (ступени, ямы, отсутствие пандусов) и строят маршрут с минимальным общим штрафом. Также умеет читать текстовые жалобы и автоматически помечать проблемные места на карте.
- **Зачем?** Чтобы человек на коляске не уперся в неожиданный высокий бордюр. А городские власти могли видеть реальные проблемные зоны на карте данных, а не гадать, где ремонтировать тротуары в первую очередь.
- **Где?** Как бэкенд (API) для существующих карт (Яндекс, 2ГИС), как внутренний инструмент для департаментов благоустройства или как основа для Telegram-бота.
- **Когда?** Работает круглый год. Пиковая потребность: осень-зима (гололед, сугробы), а также периоды, когда город отчитывается по госпрограмме «Доступная среда».
- **Для кого?** 
  - Департаменты транспорта и соцзащиты (B2G).
  - Разработчики картографических сервисов и застройщики новых ЖК (B2B).
  - Волонтерские организации и сами жители (B2C).

## Экономика проекта (Почему это имеет смысл)

Никто не будет платить за код просто так. Ценность проекта в **экономии денег**:
1. **Для города (B2G):** Отправить комиссию из двух человек проверять 100 дворов на наличие доступной среды — это неделя работы, бензин и зарплаты (условно 150–200 тыс. руб.). Мой скрипт анализирует данные и выдает отчет за 5 минут. Продажа такого пилотного отчета по одному району может стоить 50–100 тыс. руб., что для бюджета города копейки.
2. **Для бизнеса (B2B):** Застройщики обязаны делать дворы доступными. Если при проверке найдут нарушения, будут штрафы и переделки. Использование сервиса на этапе проектирования дешевле, чем исправлять ошибки потом.
3. **Гранты:** Проект идеально ложится в тематику социальных инициатив (например, грант "Студенческий стартап" на 1 млн руб. для доработки).

## Стек технологий

- **Python 3.10+**
- **OSMnx, NetworkX** — загрузка карт и алгоритмы на графах (Дейкстра)
- **FastAPI + Uvicorn** — быстрый REST API
- **Pandas** — обработка таблиц с жалобами
- **Transformers (Rubert)** — базовый NLP для анализа текста жалоб
- **Folium** — отрисовка карт в Jupyter Notebook для демо
